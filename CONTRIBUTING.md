# Contributing

Use focused changes and describe the hardware/ROM profile used for any device results. Run `bash tools/test.sh`; firmware changes should also build with ESP-IDF v5.5.3 for esp32c3. Distinguish host checks, serial-injected input, and physical button/display observations.

Never attach ROMs, game saves, firmware dumps, tokens, personal badge files, or unreviewed serial logs. A useful issue includes the SDK revision, badge revision, settings, reproduction steps, and sanitized status/error output. The project is currently specific to the 4 MiB Hack the North 2026 badge.
